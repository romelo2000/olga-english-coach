## Возможности

- 22 режима практики: диалоги, грамматика, письмо, диктанты, перевод
- 6 игр: Contexto, Taboo, Detective, Survival, Time Loop, Word Game
- CEFR-курс A1-C2 с теорией и упражнениями
- Интервальное повторение (SRS, алгоритм SM-2)
- Голосовой ввод (macOS Speech / Windows SAPI)
- AI-генерация рассказов, адаптация статей, Knowledge Graph
- Аналитика прогресса, streak-система, XP
- 7 дней бесплатного триала
- Лицензия с привязкой к устройству

## Системные требования

|-----------|-----------|
| macOS | Apple Silicon (M1+), macOS 13+, 8 ГБ ОЗУ (16 ГБ рек.) |

~10 ГБ для Ollama + AI-модель (загружается автоматически при первом запуске).

## Установка

### macOS
1. Скачайте DMG по ссылке выше
2. Откройте и перетащите приложение в Applications
3. При первом запуске визард установит Ollama и предложит выбрать AI-модель

### Windows
1. Скачайте Setup EXE по ссылке выше
2. Дважды кликните — установщик сделает всё сам
3. При первом запуске визард установит Ollama и предложит выбрать AI-модель

**Python устанавливать не нужно** — он встроен в приложение.
