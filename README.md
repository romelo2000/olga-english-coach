# Olga English Coach

**AI-репетитор английского языка, работающий локально на вашем Mac через Ollama.**

Без облака. Без подписок на серверы. Без слежки. Ваш прогресс и диалоги остаются только на вашем компьютере.

## Возможности

- 💬 **Живые диалоги** с AI-репетитором (стриминг ответов в реальном времени)
- 📐 **Грамматика по уровням CEFR** (A1 → C2)
- 🔁 **Интервальное повторение** (FSRS-6 алгоритм)
- 🎤 **Голосовой ввод и вывод** (macOS Speech + TTS)
- 📊 **Аналитика и прогресс** (XP, streak, еженедельные цели)
- 🎮 **6 интерактивных игр** (Word Battle, Language Survival, Detective, Time Loop, Contexto, Taboo)
- 📖 **Слово и идиома дня**
- ✍️ **Письмо, диктанты, ролевые игры**
- 📚 **Адаптация статей** по URL
- 🧠 **AI-генерация рассказов** с SRS-словами
- 🌐 **Knowledge Graph** (синонимы, антонимы, коллокации)
- ⚡ **22 типа практики** (Shadowing, Minimal Pairs, Collocations, Phrasal Verbs и др.)

## Установка

1. Скачайте DMG-файл из [Releases](https://github.com/romelo2000/olga-english-coach/releases)
2. Откройте DMG и перетащите `Olga English Coach.app` в Applications
3. При первом запуске приложение автоматически:
   - Предложит установить Ollama (если не установлена)
   - Предложит скачать AI-модель (~5 ГБ)
   - Проведёт placement-тест для определения уровня
